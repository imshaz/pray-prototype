Prayer Ministry Module

A prayer ministry, run the way a community actually runs one.

This is a walkable preview of the Prayer Ministry module — the public request form, the monthly guide, the focus calendar, the recorder log, and the praise report. It is shown for Charleston United ("Pray Charleston"), the first community to use it, but every screen is built to work for any community on the platform. Click through as each kind of user to see how the pieces fit together.

Switch who you are

Top-right of every screen is a persona switcher — Public, Ministry Admin, Church Leader, Recorder, Pray-er. It changes the whole view to that person's experience. Start as Ministry Admin to see the most.

Turn on the notes

The Show notes button reveals margin annotations that explain what each screen does and — where relevant — which behaviour is real versus simulated. They are on by default; turn them off to see the interface clean.

Five things this module needed that the platform did not have

Most of the module reuses what the platform already does — organisations, members, events, geocoding, reporting. These five are genuinely new, and the prototype shows what each looks like in use.

01

Send to a group

One message to all leaders, one church, or everyone inactive — the platform could only notify one person at a time.

02

Public submissions

The first time the platform accepts content from someone not logged in — with review, abuse protection and privacy.

03

Events that repeat

A monthly huddle created once and recurring on every date, each with its own RSVPs and reminders.

04

Delegated access

Help run the ministry without gaining the power to manage every user — a platform capability, not just prayer.

05

Nothing hardcoded

Name, regions, rotation, indicators, even the word "church" — all set by each community, not built in.
